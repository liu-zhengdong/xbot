# v0.3.1-beta.12

自 `beta.11`（发布说明与账号默认服务）以来，这一包主要是**同账号多设备**和**升级体验**两件事，外带几处界面打磨。仍是预发布 tag。

## 同账号的多台电脑

- **侧栏会列出同账号其他电脑上的 Bot**（按设备分组，在线/离线、最近在线时间都有）。只列同账号设备：两台机器登录的必须是同一个账号，否则各看各的。本机除外。
- 点开另一台电脑上的 Bot 就是**真的聊天**：本机用账号会话在管道上现领一张票，代理到那台电脑自己的对话接口。目标电脑不在待命、不在账号里、Bot 不在它报的名单上，都会直接拒绝并说明，不会静默失败或转发到别处。
- 这条线路**默认打开**；不想让本机为聊天开管道的话，`XBOT_ACCOUNT_CHAT=0` 关掉，侧栏也就不会再提供入口。

## 装到新机器上就能登录

- 桌面版没设 `XBOT_ACCOUNT_API` 时**默认连官方账号服务**，不再在进程里起一个空账号库（那会让任何密码都提示「邮箱或密码不对」）。`xbot serve` 和测试仍用进程内替身，`XBOT_ACCOUNT_API=local` 可显式要求替身。

## 升级更及时

- 自动检查发布列表的间隔从 **6 小时改成 5 分钟**（启动 30 秒后第一次），发版后几分钟内顶栏就会亮「更新」。每小时 12 次，远低于 GitHub 未认证额度。
- 有新版仍是在后台下载、校验 SHA256，点一下装好并重启；Windows 因为要走安装器，按钮是「下载新版」。

## 界面打磨

- 头像：随机角色头像改为模块化拼装，选择器里能看零件。
- 设置：「关于」页改成分组版式；供应商的模型能力详情收成一行；账号行简化、设备默认名更直观。
- 侧栏与投递：重启按钮换成更轻的样式；消息焦点留在圆角气泡内；鼠标悬停状态图标不再带出订阅信息；回复流式输出时仍可回看更早的历史；模型等待时状态行保留工具描述。

## 安装

见 Release 附件 `INSTALL.md`。macOS 用 arm64/amd64 的 `.dmg`；Windows 用 `setup.exe`。本包无开发者签名：第一次打开需按 INSTALL 放行 Gatekeeper / SmartScreen。

已经装着 `beta.11` 的机器不用手动换包——它自己会发现这一版并亮按钮。注意第一次仍按旧节奏（最多 6 小时），装上 `beta.12` 之后才是 5 分钟。

## 还没做 / 已知

- 跨机对话：账号电脑暂不显示未读数和最后一条预览；对方离线时不能排队，只能等它上线；单条回包受 pipe 大小限制（约 700 KiB），超长回复会被拒。
- 账号设备的对话通道只做了单机/测试桩验证，真机双机长对话还在观察。
