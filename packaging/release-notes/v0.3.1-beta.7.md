# v0.3.1-beta.7

XBot 自己发现新版本、在后台下载好，窗口右上角点一下「更新」就装好并重开。数据不动。

## 改了什么

以前那条自动更新链在真实发布上根本走不通，四处都对不上：

- 检查用的是 GitHub 的「最新 Release」接口。它从不返回预发布，而 XBot 至今只发预发布——永远是「已是最新」。
- 要找的文件名是 `xbot_<系统>_<架构>`，那是早期发布脚本的命名。现在的产物叫 `XBot-<版本>-macos-arm64.zip` 这一类，名字对不上。
- 装的时候只换 `.app` 里那个二进制，应用本体和 `Info.plist` 不更新。
- 桌面版被显式关掉了自动检查，窗口版压根不去查。

现在：

- **查**：拉发布列表，取版本号最高的那个（预发布也算），不按 GitHub 的排列顺序。`beta.10` 排在 `beta.6` 后面，不会认错。
- **下**：按平台挑包，在后台静静下载，校验 `SHA256SUMS` 才解包。不匹配就整个丢掉，已装的版本一个字节不动。下载期间界面不打扰你。
- **装**：macOS 换的是整个 `XBot.app`，不是里面那个文件。旧的先挪开，新的放进去；放失败就把旧的放回原处。数据目录在另一个盘也照常换。
- **界面**：顶栏出现一枚「更新到 0.3.1-beta.8」，点一下装好、重启，页面等新版本回来自己刷新。手机上只显示图标，不挤标题。
- **重启**：窗口版等旧进程真正退出后才启动新的（否则新进程会撞上还没放开的锁，窗口就再也打不开了），并且把启动时收好的模型密钥重新带上，更新完不用再填一次。
- Windows 用安装包更新：点「更新」是下载新的 `setup.exe`，双击运行，数据保留。

`xbot upgrade [--check]` 在命令行走同一条路径，装完提示重启。

## 怎么验的

拿真实的 `v0.3.1-beta.5` 构建、真实的 `v0.3.1-beta.6` 发布包，在 `/tmp` 的沙盒应用里跑完整流程：下载 17 MB、校验、换 bundle、版本从 beta.5 变成 beta.6，bundle 里图标和 `Info.plist` 都在，没有残留。网页那枚按钮在真实浏览器里出现、点下去发出安装请求、服务重启、新版本号回来，都实测过；320/390/1280 三个宽度都看过排版。

## 还没做

- 只校验 SHA256，不校验签名。安装包没有开发者签名，也还没有 Team ID 可比对；等有签名再补这一层。
- 不是增量更新，每次全量下载（约 17 MB）。
