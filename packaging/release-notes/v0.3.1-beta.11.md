# v0.3.1-beta.11

自 `beta.10` 以来的一组大改：工具调用统一收口到实例自己的 CLI、账号共享设备能真正执行、面板拆成工作区标签、桌面端可续聊的子代理，以及一批聊天主列的打磨。仍是预发布 tag。

## 工具收口到实例 CLI

- shell 三件套、子代理三读、`restart` 与 `http_request`、技能读写、写自己的职责/资料、Bot 之间的消息与群、例程 CRUD、删除与创建，都改走实例自带的 CLI（`XBOT_BIN`），退役了对应的原生工具门；写操作沿用原来的确认与脱敏。
- 对外的权限表没变宽：调用链、审批、掩码复用原来那一套，只是换了个入口。

## 账号与多设备

- 账号共享的设备与执行目标能真正跑起来（后端 + 前端），跨机执行走已配对管道。
- 会话签入改为从本机已有登录态导入，首次打开不再要求重新走一遍 OAuth。

## 面板与工作区

- 聊天抽屉换成工作区标签；单列视图、经验搜索、可链接的对话记录浏览器（事件详情可折叠）。
- 每台机器一份产品保险箱，按 Bot 管各自的保险箱设置；主人头像单独一份。
- 头像种子、资料改名、技能浏览都接到运行中的内核，改完即时生效。

## 子代理

- 本地子代理可以续聊：独立的标签页、有限轮次之间保留子身份、消息与记录窗口能看到子代理那边的过程。

## 聊天主列

- 引用与就地阅读：回复带引用、点引号跳到原文；对话路径里直接看资源。
- 搜索改成右上角浮卡，输入框独立，摘要去掉 markdown 记号，深色下不再像块黑板。
- 发送后自动贴底、轻微上翻不丢跟随；消息时间栏固定 24px，流式落地不再把下面顶一下。
- 「本次使用：自动」的设备条目放在输入框下方；切走再切回正在干活的 Bot，跳动点会自己回来。

## 供应商页

- 详情页状态不再自相矛盾：失效时给「重新登录」并收住排版；点开详情不再被刷回列表。
- 图标带版本号，浏览器里缓存过的坏图能重新拉一次；加载失败退回通用图标，不再留空块。

## 开发与测试

- 开发模式静态文件一改就自动刷新；`POST /api/dev/reload` 可以重新编译并换进程。
- 设置页采用 Magpie 的配置行样式，工作区布局统一。
- `internal/web` 的浏览器用例红单清零：整包实跑 `ok xbot/internal/web 173.325s`，`--- FAIL` 计数 0。多数真因是页面或事件协议改过、用例还盯老路子。

## 发给日常使用的你

- 安装步骤和第一次打开的放行方式见附件 `INSTALL.md`，安装包没有开发者签名。
