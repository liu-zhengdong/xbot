XBot 桌面版 v0.3.1-beta.1（预发布）

这是第一个带桌面安装包的预发布版本，由 GitHub Actions 从主线自动打包。安装包没有开发者签名，第一次打开要放行一次，步骤见附件 INSTALL.md；下载后可用 SHA256SUMS 校验。

## 下载哪一个
- macOS 13 及以上，Apple 芯片：XBot-0.3.1-beta.1-macos-arm64.dmg（或 .zip）
- macOS 13 及以上，Intel：XBot-0.3.1-beta.1-macos-amd64.dmg（或 .zip）
- Windows 10/11：XBot-0.3.1-beta.1-windows-amd64.zip（ARM 电脑用 arm64）
- Linux：xbot-0.3.1-beta.1-linux-amd64.tar.gz（`xbot app` 需要 WebKitGTK 4.1）

## 相对 v0.3.0 的主要改动

桌面版
- 新增 `xbot app`：双击打开窗口，不用登录码；关窗口即退出；窗口记住大小和位置。
- macOS（.app/.dmg）、Windows（XBot.exe）和 Linux 安装包；一个数据目录只能开一个 XBot，避免桌面版和终端里的 serve 互相干扰。

界面
- 对话里只放对话：定时唤醒、子任务和后台命令显示为灰色系统行，点开看原文；不再露出内部任务编号。
- 确认卡片写清要发什么、发给谁（「发到 某主机」、引用正文、「查看命令」），倒计时说明到期自动取消、不会执行；按钮是「不发 / 发送」，结果用文字写明。
- 等你确认的后台任务显示「等你确认」并能一键跳到卡片；头像栏有在跑和待确认的状态点；停止需要再点一次。
- 发送失败或没送到时原文回到输入框，不会丢；排队的消息标「已排队」；错误和状态都用中文，原始信息收在「详情」里。
- 侧栏、通知、任务预览去掉 Markdown；编辑资料改为右侧抽屉；头像统一灰色单字母或双字母；自带中文字体，各系统显示一致。

记忆与跨设备
- 记忆改为文件夹（memory.md 加按月日志），用文件工具编辑，写入有保护；只读检索给出 文件:行号，中文检索更准。
- 跨设备：邀请码配对、端到端加密、发件箱重试与退信、能看到配对设备上的 Bot。
- Bot 名字可以用中文等任意文字。

定时与安全
- 定时任务按本地时区计算，停机或睡眠期间错过的会汇总成一条提示。
- 保护数据目录里的密钥文件；远程配对等操作需要用户确认；不可信来源触发的操作更严格。

## 已知限制
- 安装包没有开发者签名和公证（macOS 为 ad-hoc 签名，Windows 未签名），第一次打开按 INSTALL.md 放行。
- 还没有在 macOS 和 Windows 真机上完整测试，欢迎反馈问题。
