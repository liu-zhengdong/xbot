XBot 桌面版 v0.3.1-beta.2（预发布）

这一版把「解压、自己放文件、手写密钥文件」换成了正常的安装流程。安装包没有开发者签名，第一次打开要放行一次，步骤见附件 INSTALL.md；下载后可用 SHA256SUMS 校验。

## 下载哪一个
- Windows 10/11：XBot-0.3.1-beta.2-windows-amd64-setup.exe（骁龙等 ARM 电脑用 windows-arm64-setup.exe）
- macOS 13 及以上，Apple 芯片：XBot-0.3.1-beta.2-macos-arm64.dmg
- macOS 13 及以上，Intel：XBot-0.3.1-beta.2-macos-amd64.dmg
- Linux：xbot-0.3.1-beta.2-linux-amd64.tar.gz（`xbot app` 需要 WebKitGTK 4.1）
- 不想安装：windows-*.zip 是便携版，macos-*.zip 里是 XBot.app

## 相对 v0.3.1-beta.1 的改动

安装
- Windows 安装程序：按用户安装到 `%LOCALAPPDATA%\Programs\XBot`，不要管理员权限；开始菜单快捷方式，桌面快捷方式可选；在「设置 → 应用」里能卸载；直接运行新版即可原地升级，`%USERPROFILE%\.xbot` 里的数据保留；缺少 WebView2 运行库时会提示并帮你装上。
- 安装程序不读写 PATH 或任何环境变量。每次发布前 CI 都在 Windows 上静默安装、升级、卸载一遍，核对用户环境变量（含类型）和系统 PATH 一个字节都没变。
- macOS 磁盘映像改成拖拽安装窗口：XBot 和「应用程序」并排，背景上有提示。

第一次启动
- 桌面版第一次打开会先让你粘贴模型 API key，测试通过后保存在本机数据目录（只有你的账户能读），不用再手写 `~/.xbot/env`，也不会设置系统或用户环境变量。以前的 `env` 文件照常可用。

跨设备
- 没有自己配置网关时，默认使用官方网关 https://xbot.babelgo.cn；只有在已配对设备或有未用的邀请码时才会联网。`xbot remote gateway default` 可以恢复默认，也可以自建网关（见 docs/gateway-selfhost.md）。

相对 v0.3.0 的其他改动见 v0.3.1-beta.1 的发布说明。

## 已知限制
- 安装包没有开发者签名和公证（macOS 为 ad-hoc 签名，Windows 未签名），第一次打开按 INSTALL.md 放行。
- 还没有在 macOS 和 Windows 真机上完整测试，欢迎反馈问题。
