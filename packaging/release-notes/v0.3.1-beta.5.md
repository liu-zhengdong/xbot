XBot 桌面版 v0.3.1-beta.5（预发布）

这一版修了一个看着很怪的毛病：对话里会出现你没说过的话。装法、下载清单和放行步骤与 beta.4 相同，见附件 INSTALL.md。

## 改了什么

对话不再替你说话
- 以前后台任务每跑满一段步数，内核会往对话里写一句「[继续] 上一段用完了步数上限，接着做」，界面上显示成你自己发的消息。同类还有完成提醒和停下说明。现在这些内核写给模型的注记都带来源标记，界面按标记隐藏，不再靠猜文字开头。
- 你自己打一句以「[继续]」开头的正常话，也不会被误当成注记藏起来。

后台任务不再按步数分段
- 后台一次跑到底，不再每 8 步（工程型 24 步）被打断、总结、再接着开一段。步数只剩一个防呆上限（1000），正常任务撞不到。
- 一件事能干多久，改由墙钟预算管：聊天型 45 分钟、工程型 2 小时。以前这个预算只能在代码里看，现在能改：`xbot profile set <名字> --background-max-time <分钟>`，负数表示不设上限。
- 顺带省掉每段一次多余的「停下并总结」调用。
- 原来那套「连续几段都没干什么就提前停」的保护，随分段机制一起删掉了；后台的时间现在只由预算和重复动作检测来管。

## 已知限制
- 安装包没有开发者签名和公证（macOS 为 ad-hoc 签名，Windows 未签名），第一次打开按 INSTALL.md 放行。
- 还没有在 macOS 和 Windows 真机上完整测试，欢迎反馈问题。

相对 v0.3.0 的其他改动见 v0.3.1-beta.1 的发布说明。
