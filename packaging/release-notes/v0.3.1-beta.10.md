# v0.3.1-beta.10

自 `beta.9`（输入框可贴图）以来的一大包日常能力：账号与多设备、语音、记忆面板、长对话窗口、例程挂技能、公式块，以及一串聊天主列与设置打磨。适合正式装到本机当日用版（仍为预发布 tag）。

## 账号与设备

- **本机可免账号日用**，需要时再在设置里登录/管理账号；账号关联设备可见。
- **多设备**：侧栏按设备看 Bot，跨机聊走已配对管道（细节以本机设置为准）。
- 远程控制台大响应（如长 transcript）改为窗口翻页，避免 pipe 单次正文顶满。

## 聊天主列

- **长对话窗口**：默认只拉尾部，上翻 prepend；本 Bot 历史可搜索（FTS）。
- **增量刷新**与 stick-to-bottom 滚动，避免整页重渲抖屏。
- **投递时间线**与主列读取分离；去掉多余「正在回复」文案，忙碌态共用工具 description。
- **气泡拆分**、单图按栏宽约 ⅓ 显示、多图缩略；删 Bot 确认用 nestcard。
- **心里话**：短旁白经来源行「查看心里话」悬停查看（不进主气泡）。
- **公式块**：像公式的围栏按行渲染为可点复制的公式条（`$`/`$$` 仍走 KaTeX）。

## 语音与媒体

- **语音交流**：按住说话发语音文件；Bot 听文件、回语音靠 TTS 落盘再挂音频（非实时通话）。
- 语音簇与播放进度继续打磨；粘贴超大图服务端等比缩到长边 2048 再落盘。

## 记忆与提醒

- 右侧记忆面板：**memory.md 整篇** + 经历按条带时间。
- 记忆将满/自省提醒走现有 system-reminder 通道，不硬截断。

## 模型、供应商与连接

- **自定义供应商**可从模型设置添加；OpenCode Go 等内置供应商补齐。
- 生图：有 hosted 用厂商，否则走全局图片生成设置；网页搜索/生图分区标题对齐。
- 连接应用：设置内密钥弹层与安装前校验。

## 例程与其它

- **例程可挂已有技能**（任务行里编辑）。
- 环境时间等语义公告开始走统一注册缝（后续可接更多字段）。
- xbot-dev 默认桌面壳；Bot 可调重启并续跑提示。

## 安装

见 Release 附件 `INSTALL.md`。macOS 用 arm64/amd64 的 `.dmg`；Windows 用 `setup.exe`。本包无开发者签名，第一次打开按 INSTALL 放行 Gatekeeper / SmartScreen。
