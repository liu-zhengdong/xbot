# 子代理

主线有全部已挂载工具，短活自己做，长活可以交给子代理，保持用户随时能说话。启用 agents 和 dispatch 时，用 `dispatch(type, task)`；未启用 typed dispatch 的配置可能提供旧 `spawn`。只使用当前工具目录里实际存在的入口。

内置类型是 research（只读，20 分钟）、dev（开发，2 小时）、general（通用，45 分钟），实例可用 `<root>/bots/<bot>/agents/types/` 覆盖。任务说明要带目标、目录、约束和怎样算对；子代理默认空白上下文，不能假定知道主线全部对话。

本地执行器最多同时跑 3 个、排队 8 个；会写同一工作资源的任务按资源排队。通过 `steer` 补充、`queue` 排后续消息、`interrupt` 打断、`cancel` 取消，不因追进度重复起同一任务。

状态走环境流；结果作为普通消息回主线，全文在任务目录 `<root>/bots/<bot>/agents/<id>/result.txt`，主线按回报路径读取。用户可以在任务/轨迹看状态。主线核对约定验收的产物及测试证据，不能把子代理一句「通过」或 done 状态当成自己验证过。外部编码代理另走 coding-agent Link，不占用这套子代理记录。
