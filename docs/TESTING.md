# 验证范围与资源预算

2026-11-01 用户调整：按影响选择验证，默认一次，通过即停。取消每次全仓加修改包三遍、全部旅程冒烟和每一步完整截图矩阵。
本文件是 XBot 测试执行范围的统一约定，优先于引用技能的通用测试流程。旧设计和里程碑中的命令记录不是新的运行门槛。产品正确性和安全边界不变。

## 选择最小有效范围

开始前简述改动、影响面和选用检查，不另写测试计划文档。

| 改动 | 默认验证 |
| --- | --- |
| 文档、注释、流程 | diff、格式、链接；不跑 Go、浏览器、冒烟或性能测试 |
| 文案、小样式、局部 UI | 受影响页面和必要交互；有行为变化才跑对应浏览器用例 |
| 单包业务或接口 | 对应回归一次；多个入口受影响时再跑整包及直接调用方 |
| 测试或夹具 | 新增或修改的用例一次；共享启动器改动选代表用例 |
| 跨包协议、共享状态、调度、存储、认证或权限 | 受影响包及相关旅程一次；无法限定影响面时全仓一次 |
| 发版、依赖、构建链或明确全面验收 | 全仓一次，加相关端到端或平台检查 |

S/M/L 是设计和评审分档，不自动扩大测试。格式、vet、lint 也按影响选择：改动的 Go 文件做 gofmt，有 Go 变动时 vet 相关包；纯文档或静态资源不跑全仓 vet。

## 一次通过后停止

- 本地默认 `go test ./相关包 -run '^Test相关行为$'`，需要整包时去掉 `-run`。允许使用有效缓存；只有需要新执行证据时才加 `-count=1`，不默认三遍。
- 同一代码、平台和配置下，Agent、负责人、复审者共用日志，记录命令与代码版本，不各自再跑一套。
- 高层检查已覆盖的用例不叠跑：全仓已含长程测试就不单跑；整包已含相关回归就不为收尾再跑。
- 通过后，只有影响被测行为的新代码、失败或具体疑点才重跑相关部分。文档、提交或合并相同代码不会使结果失效。
- 不并行启动覆盖相同包的多套浏览器或全量测试，避免争抢资源、端口和临时目录，污染性能数据。

## 过时测试及时删除

- 功能已删除、需求已被明确取代、接口已退役，或测试完全重复且没有独立覆盖时，删除对应旧用例和不再使用的夹具、辅助代码。不为通过旧测试恢复已放弃的产品行为。
- 混合测试只删过时部分，仍有效的行为迁到当前入口；已有覆盖可以复用，不要求每删一条再写一条同构测试。仅夹具或请求格式落后时，更新夹具，不能连有效业务断言一起删。
- 确认过时就在当前相关改动中清理，不长期挂成“已知基线失败”，也不用 skip、放宽断言或无条件通过留下空壳。
- 删除时简述废止依据和仍有效行为的覆盖位置。测试失败、偶发、跑得慢或环境受限本身不是过时证据；有效契约上的缺陷仍须处理。

## 何时加重

- 偶发或并发问题：先定位同步、生命周期和隔离，选择定向 `-race` 或有限复跑，写明次数和停止条件；整包三遍不是并发证明。
- 行为修复：要有命中缺陷的回归证据，优先复用已有用例；复杂修复做定向红绿验证，不机械回退整包，不为文档或低影响样式新增同构测试。
- 端到端：入口、装配或跨组件行为改变时选相关真入口一次，不同入口有不同风险再补；模型与外部服务用 fake/scripted。
- 性能：涉及延迟、吞吐、资源、动效或明确性能目标才测相关指标；其他里程碑不强行补数字，不用测试耗时冒充产品性能。
- 模型评测：普通开发只用 fake/scripted。真实模型仅执行当前任务已授权的专项，写明样本、费用预算和停止条件，不因通用验收自动增加轮数。
- 基线失败：先判断是否仍对应现行契约，退役断言按上节删除；有效契约的失败需要归因时最小复现一次并记录；相同失败不随无关改动重跑全套，不重复到绿，不随手扩修当前任务之外的问题。

## 浏览器与截图

局部改动检查稳定最终状态，默认一个代表视口。主题受影响才补明暗，响应式受影响才补断点，桌面壳受影响才补对应平台。
整体改版在功能收敛后覆盖受影响页面的明暗主题和代表宽度；交互状态按实际风险选，不做页面、状态、宽度、平台的机械全组合。
复用浏览器和夹具。像素差用于具体视觉回归疑点或整体改版，不是每次提交必经步骤。已有原型定稿要求不变；独立视觉评审针对稳定版本的实质变化，不逐个微小编辑重复评审。

## CI 与汇报

CI 保留 Linux 全仓一次、关键包 race 和跨平台构建作集中兜底；本地不为复制 CI 结果再跑全套。同分支新提交取消旧 CI，发布与安装流程不受影响。
纯文档提交不触发产品构建测试。`prompts/`、配置和脚本是运行输入，不能因 Markdown 后缀当纯文档跳过。
汇报实际检查、结果和范围；未跑项说明与改动无关、已有覆盖或具体未解决风险。按本约定选较小范围是正常执行，不需另请用户批准；相关检查失败仍须修复或归因，不能跳过后声称全绿。
