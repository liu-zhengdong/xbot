# 聊天页顶部标签原型

范围：独立交互原型。页面和记录均为演示数据，不请求 XBot API，不调用模型。

打开 `index.html` 即可预览；也可以在仓库根目录运行 `python3 -m http.server 8766 --bind 127.0.0.1`，访问 http://127.0.0.1:8766/docs/prototypes/chat-tabs/ 。字体与基础视觉变量引用仓库现有文件，无外网依赖。

设计重点：

- 顶部两层：Bot 身份与操作、可扩展的页面切换栏。
- 顺序：聊天、记忆、轨迹、任务、上下文、收件箱、更多。聊天固定第一项。
- 常用标签直接露出；更多菜单可控制其余标签的显示。窄屏标签横向滚动。
- 各标签使用完整的主内容区。切换保留聊天记录、滚动位置与输入草稿。
- 聊天保留较宽的留白，底部输入框固定。记忆按全文与经历分栏，轨迹按轮次折叠。
- 视觉沿用 XBot 中性灰体系与现有 tokens，不加分隔线，颜色仅用于在线、上下文和子代理类型。

可体验：标签切换、标签显隐、左右方向键切换、深浅色、侧栏收放、演示消息发送、轨迹展开、记忆经历展开、例程开关、Bot 查找。选择附件只显示文件名，不上传。

`?tab=memory` / `?tab=trace` 可直接进入对应页面；`?theme=dark` 可直接查看深色。

`previews/` 为 1440 × 900、DPR 2 的浏览器截图，另有 390px 窄屏截图。此目录保留用户确认的原型；正式页面已按 [ADR 0042](../../adr/0042-chat-workspace-tabs.md) 接入既有 API，现状见 [UI atlas](../../atlas/ui.md)。

对照回顾：复用现有的记忆全文、经历、任务、原始轨迹、上下文、收件箱内容；对话仍只展示用户与 Bot 消息，工具步骤保留在轨迹。此次只调整内容入口与展示空间，不增加 ADR 0021 以外的状态或通信机制。

原型验证：Chrome 无头浏览器通过六个标签切换、草稿保留、演示发送、轨迹展开、标签显隐、键盘导航、主题切换，以及 390 / 768 / 1440px 宽度下无页面横向溢出的检查。原型自身不涉及 Go 或后端。正式实现的验证记录见 [改版设计](../../dev/chat-tabs.md)。
