# 网页界面

> **30 秒版**：对话里只放对话，工具调用进信息面板的轨迹；确认卡写进 transcript；侧边栏按分组。

## 边界
负责：网页界面的展示规则。接口见 [API.md](../API.md)。UI 先由审美顾问出原型，主人定稿再实现。

## 怎么运转
桌面版 `xbot app [--port 8787]`（[ADR 0007](../adr/0007-local-first-desktop-app.md)）在同一进程里跑 serve（不开隧道、不自动升级、不打印登录 token），只绑 127.0.0.1，用 `internal/appshell`（唯一引用 MyGo 的包）开系统 WebView 窗口。窗口打开 `/app/launch?code=…`：一次性登录码 32 字节随机、60 秒过期、用一次就作废，换成正常的会话 cookie 后跳到 `/`，所以桌面用户看不到登录页。同一个数据根只能开一个（`app.lock`）；端口被占时在改动数据之前就报错退出。关窗即退出。

对话里只放对话。工具调用不进消息流，改到信息面板的「轨迹」：一轮一行，写上时间、用过的工具和耗时；点开一行再看每次调用的参数和输出。输出默认截断，需要时再展开。要主人确认的操作仍在对话里给出确认卡片。确认卡片也写进 transcript：先记一张 pending，主人决定后追加一张终态（approved、declined）。服务端默认等 24 小时，待确认的卡带 `deadline`（RFC3339）。网页倒计时读这个时间；旧卡没有该字段时，从卡片写入时间起算 24 小时。剩余时间长就按「23 小时」显示，不按秒。决定接口返回 410 时，这张卡显示为已过期。到时仍没人答，追加 `no_decision:expired`，模型看到的是「过期、没有决定」，不是主人拒绝。这一轮从前台转到后台时，卡片继续等，不作废。显示卡片的那次请求已经结束时，主人仍可以用 `POST /api/bots/{name}/approvals/{id}` 决定（见 [API.md](../API.md)）。进程重启时，上一个进程留下的 pending 卡一律追加 `no_decision:restart`，不留下看起来还能点的卡。同一个 id 只显示最新的一张，回复结束或刷新页面后卡片仍在，状态就是最后的决定；这些卡片行不进模型上下文，也不进记忆抽取。Bot 名字保留原样的大小写（默认 Bot 叫 XBot），可以用的字符是任意文字的字母和数字，外加 _ 和 -，路径分隔符、控制字符、空白和超过 64 个字符（或 255 字节）的名字都不行，名字本身就是要落盘的目录名。Bot 还在跑的时候，对话里只留一个轻的进行中提示。轨迹不画时间轴分轨，也不拆上下文占比。点开「发给另一个 Bot」那一行，就在当前对话里看他们俩的往来，只读，可以返回。标题是叠在一起的两个头像，后面是两边的名字，中间一个小圆点。没上传照片时，头像是低饱和的软边圆斑，颜色和轮廓都由名字决定，不是正圆笑脸。侧边栏按分组收起展开，数量写在标题上，折叠记在这台浏览器里。Bot 的更多菜单里可以移到分组。分组标题上可以改名或删除，删除不带走 Bot。界面自带可变字体 Mona Sans VF。中文接着用系统里已有的苹方、思源黑体、Noto Sans SC。

状态走只读接口，和别的接口同一套登录：`GET /api/bots/status` 返回 `{bots:[BotStatus]}`，含全部同一主人的 Bot，不带步骤；`GET /api/bots/{name}/steps?n=20` 返回 `{steps:[...]}`，是这个 Bot 当前这一轮的步骤环，`n` 最多 20。`GET /api/bots/{name}/todos` 返回待办清单。`BotStatus.todo` 是一行摘要，侧边栏和步骤弹层还没画它。同一个主人的远端点由本机合并进来，`node` 写上节点名；每个节点缓存最近一次状态，最多每 10 秒刷新一次，调用超时 2 秒，端点不可达时给出缓存并把 `state` 写成 `offline`、`stale_seconds` 写成缓存年龄，所以一个死节点不会拖慢 `/api/bots/status`。远端只给状态，不给步骤。节点侧的能力是 `status`，返回那台机器上各 Bot 的状态列表，JSON 最多 16 KiB，放不下就整条整条地丢并保持 JSON 合法。

切换 Bot 时同步清空对话与详情，显示灰色骨架；线程、详情与流式回复只更新发起请求时选中的对象，旧请求不覆盖新 Bot。加载失败在对话中央显示「连不上 XBot」和次级「重试」。发送先显示用户气泡与「发送中」，Bot 头像旁的三个灰点等到首个文字片段才消失；减少动态效果时灰点静止。成功后原文记录替换临时气泡，失败在原气泡旁显示「没发出去，原文还在输入框里」和「重试」，不把服务器错误放进标题。
定时唤醒和错过的定时汇总显示为居中灰色时钟行，点击展开提示词和「来源：定时」，静默回复折入定时行，侧栏跳过 SILENT 并保留上一条真实消息。
