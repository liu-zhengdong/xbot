# 网页界面

> **30 秒版**：对话里只放对话，工具调用进信息面板的轨迹；确认卡写进 transcript；侧边栏按分组。

## 边界
负责：网页界面的展示规则。接口见 [API.md](../API.md)。UI 先由审美顾问出原型，主人定稿再实现。

## 怎么运转
对话里只放对话。工具调用不进消息流，改到信息面板的「轨迹」：一轮一行，写上时间、用过的工具和耗时；点开一行再看每次调用的参数和输出。输出默认截断，需要时再展开。要主人确认的操作仍在对话里给出确认卡片。确认卡片也写进 transcript：先记一张 pending，主人决定后追加一张终态（approved、declined），超时或上下文结束仍没决定就追加 expired（界面显示「已过期」），同一个 id 只显示最新的一张，回复结束或刷新页面后卡片仍在，状态就是最后的决定；这些卡片行不进模型上下文，也不进记忆抽取。Bot 名字保留原样的大小写（默认 Bot 叫 XBot），可以用的字符是任意文字的字母和数字，外加 _ 和 -，路径分隔符、控制字符、空白和超过 64 个字符（或 255 字节）的名字都不行，名字本身就是要落盘的目录名。Bot 还在跑的时候，对话里只留一个轻的进行中提示。轨迹不画时间轴分轨，也不拆上下文占比。点开「发给另一个 Bot」那一行，就在当前对话里看他们俩的往来，只读，可以返回。标题是叠在一起的两个头像，后面是两边的名字，中间一个小圆点。没上传照片时，头像是低饱和的软边圆斑，颜色和轮廓都由名字决定，不是正圆笑脸。侧边栏按分组收起展开，数量写在标题上，折叠记在这台浏览器里。Bot 的更多菜单里可以移到分组。分组标题上可以改名或删除，删除不带走 Bot。界面自带可变字体 Mona Sans VF。中文接着用系统里已有的苹方、思源黑体、Noto Sans SC。
