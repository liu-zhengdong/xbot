# 网关（计划中，M8）

> **30 秒版**：开源可自建的网关，P2P 优先、中继兜底，只转发端到端加密消息。

## 边界
负责：跨网络、跨用户的连接和 Bot 地址。尚未实现。

## 怎么运转
- 优先 P2P 直连，打不通再走中继。可以用 Cloudflare Workers 加 Durable Objects 部署，也可以用 Go 自己部署；客户端可以填入多个网关地址。
- 网关只转发端到端加密的消息，不存记忆，也看不到内容。
- **Bot 地址**：`xbot://<公钥指纹>@<候选地址，含内网 IP>,<网关>`。连接需要对方确认；内网环境可以不经网关直连。
- 网关上可以分享 Bot 模板。
