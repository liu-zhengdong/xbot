# 0033 Bot 私有资料与共享工作空间并存

## 背景

政东确定共享层不能依赖目录是否碰巧存在；[ADR 0032](0032-bot-reference-and-optional-shared.md) 的私有默认保留，共享目录改为始终可用。

## 决定

每个 Bot 默认在 `bots/<bot>/memory/` 存私有资料。整机共享工作空间使用已有的 `<root>/memory/`，只放跨 Bot 事实；虽然目录名是 memory，它是共享层，不是私有库。采样时创建两个目录，空库也注入各自绝对路径契约和索引，先私有后共享；写入轻推给出两条路径，默认写私有、跨 Bot 才写共享。

## 后果

两个来源沿用 `reference` 环境流、提醒 sidecar 和各自 256 KiB 整源预算；关键词扫描两源并逐轮路径去重。Bot 库的系统记忆文件、日志和备份不作为资料扫描。经历仍每 Bot，压缩不写记忆；已有共享目录的内容原地保留。
