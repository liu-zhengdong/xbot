# 0004 去掉安静、适中、积极三档主动性

## 背景
Bot 档案和评测曾按安静、适中、积极三档区分主动性，评测每条要跑三遍。

## 决定
去掉三档。想怎么通知写在 Bot 自己的 persona 里。旧档案的 `proactivity` 能读进来但被忽略，不进提示、不再返回；评测每条只跑一次（再按多数跑 3 次）。

## 考虑过的方案
- 保留三档：多一个配置维度和三倍评测，实际差别靠 persona 就能表达。

## 后果
档案和接口不再有这个字段。
