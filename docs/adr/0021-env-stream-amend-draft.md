# 0021 修订提议：环境真源外置，模型面改语义公告

> **Agent 只能提议。** 本文 `status: Proposed`。在主人把本篇标为 Accepted（或改写进 Accepted 的 [0021](0021-env-stream.md) / 另发 supersede ADR）之前，**不得**把 Accepted 0021 正文改成下文，也不得按下文当已定硬约束开工编码以外的「假落地」。

## 背景

[ADR 0021](0021-env-stream.md) 定下环境流：会变的状态有变才追加、不改前缀；压缩后可在尾部补全量快照。其中一条落地成：**「已公布的值」只从对话里的环境消息回放，不另存第二份账**；消息体统一为 `<environment_update>` 内的 JSON（`set` / `null` 等，见 atlas/context 的 env_replay）。

日用与对照暴露两个问题：

1. **模型面是 JSON 信封**，时间几乎每分钟一条 `{"set":{"time":…}}`，语义弱、噪声高（候选「环境更新只发当前值」；transcript 里环境行占比实测偏高）。
2. **环境本是外部环境**：真值应在钟上（现采 / 外置投影），不该靠 transcript 当字段账本。DSH 已是双轨——操作真值现采，模型面语义散文 + 有变才追加且可 supersede——XBot 应对齐这一世界模型（见 [env-prompt-frame](../dev/env-prompt-frame.md)）。

政东 2026-10-31 纠正并点头：真源不在 transcript；公告可以进串，但不是账本。

## 考虑过的方案

- (a) **对话仍存机器 JSON，发给模型前再翻成句子**：真源仍绑在串上，和「环境是外部状态」冲突；压缩/回放继续依赖 env_replay。不采用为权威模型。
- (b) **对话里句子 + 附带机器旁路**：双份事实，易漂移。不采用。
- (c) **只有句子，靠解析反推数字**：脆。不采用。
- (d) **外置真源 + 语义公告双轨（本提议）**：对齐 DSH；Register(Field{Sample, Prompt})；有变尾部追加。采用。

## 提议决定（若 Accepted，对 0021 的修订）

### 废止 / 降级（0021 原文中的）

1. **废止**：「已公布的值只从对话里的环境消息回放出来，不另存第二份账」作为**字段真源与差分基线**的要求。
2. **降级**：`<environment_update>` 内 **JSON `set` 信封作为模型主文**的地位——不再是环境更新的主交付形态；遗留回放路径可暂时保留供迁移/测试，但不是新字段的完成标准。
3. **降级**：atlas/context 所述「环境消息可回放（env_replay.go）统一为 JSON」作为**唯一**基线叙述——须改为外置真源叙述（合入后改 atlas，不在本 ADR 抄代码）。

### 改成 / 保留

1. **真源外置**：环境字段经现采（及必要投影）持有；差分相对「上次已告知模型的渲染结果 / 外置投影」，不相对「从对话 fold 出的 JSON 基线」。
2. **模型面语义散文**：每字段（或合包）有 `Prompt` 专门构造提示词串；合包公告可带 supersede /「本条取代先前同类」声明。
3. **有变才尾部追加**公告进会话（可进串）；**不改历史、不改固定前缀**——0021 此项**保留**。
4. **压缩或折叠后**仍可在尾部追加重新采样的**全量语义快照**，不放进前缀——0021 此项**保留**，快照形态改为语义（非 JSON set 主文）。
5. **装配缝**：`Env.Register(Field{Key, Sample, Prompt})`；上层 `promptinject` / `context.Register` 光框架；新字段只经 Register。对照提醒通道 `Channel.Register`，形状同向。
6. **三件套仍成立**：只追加的对话串、环境流（改双轨后）、插话口——新需求仍先对照能否放进这三样。
7. **写记忆成功回执**与环境公告共用 framing 精神：**保留**「改一起改」；回执是否同步语义化可分批，不阻塞时间第一刀。

### 第一刀范围（实现批，非本 ADR 正文义务）

时间字段迁 Register+语义 Prompt；废 time 的 JSON set 主文。其余字段与提醒迁入光框架另批。

## 后果（若 Accepted）

- 换来：模型可读的环境提醒；真源与公告解耦；扩展经 Register，不再堆硬编码采样表。
- 代价：须迁移 `env_replay` / `encodeEnvironment` 主路径；长程与环境相关单测重写期望；Accepted 0021 与 atlas/context 环境段落要改写或标记 superseded 段落。
- 放弃：「对话即环境账本、零外置已见账」的纯净假设——承认外置投影是有意的第二面，不是偷账。

## Revisit when

- 证明「公告进串」仍严重污染判断力，需改为仅当次请求注入（比 DSH 更激进）。
- 外置投影与多进程/多设备一致性成本高于回放模型，需重开双轨设计。
- DSH 或供应商侧出现更强的原生 context 协议，值得整体换缝。
