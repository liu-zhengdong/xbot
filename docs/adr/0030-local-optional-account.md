# 0030 本机默认进主壳，账号可选

2026-10-27 · 政东决定；取代 [ADR 0025](0025-account-is-the-way-in.md) 对本机入口的决定。

本机浏览器和桌面壳不以账号登录阻断聊天和配对；设置里的账号可用于把电脑关联到账号。公网薄入口仍需账号和管道。账号表单在本机复用已有账号接口，不跨域传递会话。

本机 `GET /api/session` 仅在直接回环连接、回环 Host、无代理转发痕迹且同源时签发现有用户 cookie；远端仍须凭既有授权。账号退出在本机保留用户会话，远端退出仍清除。此决定让本机同一操作系统用户可直接访问本机助手；服务暴露到网络时不把远端请求视为本机。
