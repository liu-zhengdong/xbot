# 0075 账号共享设备池，Bot 按执行上下文操作设备

## 背景

用户要求将设备与 Bot 解耦。账号内所有 Bot 都可操作账号绑定的全部设备。用户确认交互原型后授权子 Agent 实施。

现有设备配对提供消息，实时 pipe 提供账号用户的远程界面。它们尚未提供带源 Bot 身份的直接设备执行。

## 决定

1. 设备成员归账号。绑定安装中所有本机 Bot 使用该账号设备池。新增 Bot 或设备不增加逐 Bot 授权关系。Owners 继续表达可信输入，不形成设备许可矩阵。
2. Bot 对话主机与执行设备分开。权威对话、记忆和例程保留原位置。设备执行不迁移 Bot，不要求目标设备上存在代办 Bot。
3. 直接调用目标设备能力。复用账号、实时加密 pipe、现有 Shell/文件/browser/desktop 与 Jobs。信箱继续承载异步消息，不承载稍后自动重放的 Shell 或点击命令。
4. 用户控制台与 Bot 执行使用不同的调用身份。源入口从实际运行实例取得账号、Bot和子代理上下文。目标验证账号设备成员关系。生产操作继续默认自动执行，不增加逐操作权限确认。
5. 本次设备选择随主人消息进入原运行路径。界面发送成功后将下一条消息的选择恢复自动。已受理任务的目标设备不随其他 Bot 或后续选择改变。设备离线时不静默换成本机。
6. 目标端原 Jobs 实例拥有进程和结果。外来执行上下文分别保存 cwd。稳定调用引用在发送前生成，用于回执丢失后的查询。未知时保持未知，不自动重发副作用操作。
7. 当前 pipe 的请求与响应各限 700 KiB，同连接串行且整体缓冲。使用短受理、查询、有界输出与停止请求。大文件另作有界分块，不能声称已有 SSE 或实时桌面流。
8. 解绑撤销该成员的执行资格与连接。心跳不能恢复已撤销关系。文件与对话保留，停止结果按实际事实报告。
9. 设备状态使用 ADR 0021 环境流。执行结果使用原工具回执和对话串。不增加转告签收账或独立调度中心。

## 取代范围

调整 ADR 0012 中“设备只有 Bot 消息、不提供跨机执行”的限制。旧 node 协议、自动同步身份和记忆仍退役。

扩展 ADR 0024 的实时管道调用方：除了账号用户控制台，加入账号内 Bot 的窄设备执行通路。用户控制台身份不能直接冒充来源 Bot。

保留 ADR 0010 的异步信箱与不自动同步文件、记忆的决定。无账号本机使用沿 ADR 0030。工具默认放行沿 ADR 0019。

## 备选与代价

目标设备 Bot 代办会增加模型解释和代办身份依赖，不能直接表达设备解耦，因此不采用。Bot 协作仍用于需要对方判断的任务。

接受 Bot 对话主机仍需在线，换取不迁移原有存储与调度。常在线运行可使用云电脑，但云电脑供应、计费、备份和独立屏幕另行设计。
