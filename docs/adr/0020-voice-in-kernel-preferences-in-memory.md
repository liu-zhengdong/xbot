# 0020 说话规则归内核，个人口味归记忆

> 「`language` 保留」一句已由 [ADR 0026](0026-persona-cards-replace-voice-and-quiet-hours.md) 取代（Superseded）：语言也并入记忆，口吻写进人设卡。其余仍有效。

## 决定
2026-10-21 政东定：回复像懂行的朋友说话，先说结果，转述工具与子代理结果，不向主人罗列内部代号和无须使用的技术细节。

通用说话规则由内核统一加入稳定提示词，已有和自定义 Bot 同样生效。个人口味属于 Bot 长期记忆，不再保留 `tone`、`length`、`emoji` 三份配置；`language` 保留。加载旧配置时先保存一条偏好记忆，再删除三字段；并发加载和保存失败重试不重复写。旧模板忽略这三项。

DeepSeek 的行动收敛规则只放在按模型加载的补充提示里；共享核对规则只检查任务点名的改动和验收项，到点停止，不扩大检查。

## 取舍
不只修改默认人设，因为已有 Bot 保存的人设不会跟着升级。规则不随每轮输入重复拼接，保留稳定前缀的缓存条件。个人口味从记忆中读取；迁移写不进去时明确报错，保留原配置，避免丢失偏好。

「说话」测评统计路径、内部代号和代码格式的出现次数，帮助发现技术日志式回复；这些计数不代替内容是否恰当的判断。真实模型的前后对照独立运行，不进测试或 CI。
