# 0002 前台写操作自动排到后台之后

## 背景
分叉设计初稿规定：有后台时前台的写操作直接返回一句提示，让模型自己选 steer 或 queue。

## 决定
内核自动用 `queue` 把前台写操作交给资源重叠的后台，前台告诉主人已排队；没有重叠就转成新的后台。

## 考虑过的方案
- 直接拒绝、由模型选：被取代。模型可能重复干活或放弃，主人还要多等一轮。

## 后果
规则放在权限表里判断，守门测试覆盖。
