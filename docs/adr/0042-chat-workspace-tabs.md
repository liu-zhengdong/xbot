# 0042 聊天与 Bot 信息统一为顶部主视图标签

用户认可 docs/prototypes/chat-tabs 原型并授权实现，明确本次为整体 UI 改版。

Bot 的聊天、记忆、轨迹、任务、上下文、收件箱共用主区域，顶部两层分别承载身份操作和页面导航。
聊天固定第一项，其他标签可显隐。Bot 资料、群组成员和模型编辑保持可达。

替代原先「点击顶栏身份芯片开右侧信息抽屉」的布局决定。
原有内容、API、聊天 DOM 和环境流机制继续复用，切视图不重建聊天或新增状态账。
对话仍只含原有可见消息投影，工具原文保留在轨迹。

已确认原型优先于旧布局专属的几何或静态字符串测试；业务行为与数据契约的验证保留并迁移入口。
记忆全文和经历、任务草稿和选择复制、流式回复、分页搜索、附件语音、更新和资料操作不得退化。
