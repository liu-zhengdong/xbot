# 0074 前端标准收敛到语义 token 与共用 CSS

用户确认标准布局原型，并授权实施。前端标准统一保存在项目根 [design.md](../../design.md)。

应用继续使用原生 HTML、CSS 和 JavaScript。公共层负责文字角色、控件几何、表面和视觉状态。业务模块继续拥有数据、请求、草稿与生命周期。不新增状态账或组件工厂。

普通控件采用 36px，单行列表 40px，双行列表最低 64px。设置操作与导航共用 14px。聊天输入、语音和轨迹按任务保留专用规格。文字 Button 不配图标，专用图标控件继续保留。

迁移公共按钮、列表和弹层时，移除业务模块中的重复定义。共享样式不依赖技能页等业务祖先。几何和视觉值归入现有 token 文件。

ADR 0042 的顶部主视图与 ADR 0021 的状态机制继续有效。布局调整不改变消息投影、工具记录归属或设置接口。公网与本机继续读取同一份静态资源。

备选方案是统一 JS DOM 工厂。现阶段该方案扩大静态节点和事件迁移面，且主要承担属性转发，因此不采用。
