## 实现边界

### 合伙人规则与证据

- 开工对齐结果；明确目标直接推进，影响结果的缺口先问；独立判断，部分错误分别说明。
- 主人偏题新点子进指定候选；没有候选落点时复用 Bot 记忆。指出代价，除非主人改方向，保持当前目标。
- 核对已约定的产物与测试命令、输出和退出状态，缺证据标未验证。不把下游自报/验收数值/done 当测通，不扩大检查。
- 主动必要下一步和进度跟踪，复用例程并防重复；未经授权的改方向、花钱、外发先问。默认无权限卡时已授权动作不二次问。
- 任务数和各项状态从最新回放的环境 task 项取，包括 queued/blocked，不从旧口头汇总猜数。
- 不抄外部提示词，不设计模型内心评价。

### create_bot

描述要求用途/职责未知时用 ask_user 或普通提问补清名字、用途、是否现在建，只问缺项。已清用途并给名或明确授权取名，直接建；「你定名字」不等于「你定职责」。persona 在 schema 必填，运行时拒绝空/全空白，拒绝发生在任何创建副作用之前。非空 persona 是否来自主人仍依赖模型遵循规则，不新增语义授权账本。

ask_user 的既有 30 分钟默认选择不能成为臆造职责的理由：用途未知时推荐暂缓/补充信息，或者直接普通对话问。沿原卡片机制，不修改其超时策略、不恢复 create 审批卡。

### 手册

单一版本源为 `internal/manual/sections/*.md`，go:embed 编入二进制。七节 ID：memory/context/routines/subagents/interjections/connectors/workspace。`kernel_manual(section)` 常驻挂载，readonly；section enum 仅已知 ID 与 index，未知值返回错误，不接收任意文件路径。每节测试约束不超过 16 KiB，目录提示不超过 2 KiB；均远低于节点 1 MiB。

系统规则只加入目录与先读要求；正文在原工具调用/结果路径进入对话。CLI `xbot manual` 列目录，`xbot manual memory` 等读同一正文。面板后置。目录不是实时状态，不能凭手册宣称某项能力已连接或文件已写入。

记忆术语固定 memory.md / log/YYYY-MM.md。实际目录以当前 root、Bot、person ID 和记忆标题为准；既有详情记忆入口供主人查看，也可直接编辑 Markdown。

### 人设字段落点（C1/C2）

字段的现行完整映射只放 [atlas/multibot.md](../atlas/multibot.md#人设组成与提示词边界)。本批按该表约束：简介正文退出 ComposedPersona；档案指纹仍沿环境流；职责和工作档案不迁移、不覆盖；标签不凭空新增字段（现有侧栏分组复用 group）。名字沿 config 和环境 paths/档案识别，不另拼一份名字提示。运行档位 role 与职责 persona 分开，CLI flag 保留原名但帮助明确语义；网页没有运行档位编辑入口，本批不加 UI。

## 验收 C1–C8

| 编号 | 本批验法与取舍 |
|---|---|
| C1 | atlas 表逐字段列存储、写入者、变化频率、提示入口；简介不注入、档案显示仍保留。标签/免打扰按当前代码与 ADR 校准，不新增旧设计字段 |
| C2 | 人设卡/回退 persona、记忆路径不变；规则升级用例验证职责与工作记忆字节不变；无升级迁移丢职责风险 |
| C3 | ≥3 外在行为对照：偏题写候选而非另开工；下游自报后读真实失败日志而非宣称通过；目标不清先问而非写文件。专用脚本走真 Kernel/文件工具；改前反例是脚本夹具，不冒充旧模型实测。真实模型优于改前的统计结论待独立评测 |
| C4 | profile set --role 帮助称运行档位（chat/dev）；fork --role 帮助称职责/persona；原 flag 不改，无网页改动 |
| C5 | 七节目录、section 读取、CLI 同源、内容事实测试；七次新 Bot scripted 问机制→先调手册→收到正文再回答。未宣称真实模型自动遵循已验证 |
| C6 | 不明用途脚本先 ask_user、无 Bot 副作用，补清后创建；清用途与授权取名两案直接创建；空 persona 拒绝；permissions on/off 均不为 create 加卡 |
| C7 | 五个实际调研任务的环境供脚本计数（3 跑 2 排）；只有验收值的普通回报，脚本限定为尚未验证，不转述成测通 |
| C8 | 后置。手册给出现有入口，本批不增独立“重复造轮”评分维度 |

**冒烟用例**：`internal/kernel/context_batch_c_test.go`（专用脚本集成，非真二进制端到端）、`internal/manual/manual_test.go`、`cmd/xbot/cmd_manual_test.go`；真 CLI 手册另用构建产物验；长程沿 `e2e/longrun_test.go`。不自行修改 guard 用例期望。
