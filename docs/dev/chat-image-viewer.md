# 聊天图片查看器（dev）

真源：`/workspace/xbot-ui-design/chat-image-viewer/handoff.md`；候选 `聊天图片查看器.md`。

## 目标

取代气泡点开后的多图小宫格 lightbox，做成市面 IM 量级单图沉浸查看器。

关键点：点哪张开哪张；同条多图可切（←→/滑，到头不跨消息）；双击/捏合/滚轮放大，放大可拖，切图重置；遮罩/✕/Esc 关；指示 i/n，单图不显示 1/1；勿用小宫格主导航。

## 怎样算对

- 正手：点气泡一张 → 大图沉浸；多图可切有 i/n；能放大拖；能关。
- 反手：点开仍是多图小宫格墙当主视图；或切图跳到别条消息。
- trusted 放大必须实际得到 `scale > 1` 并测绿，才交复审（主管补充要求）。

## 底线

不做下载管理/编辑标注/改生图挂图通路/线程级图库；禁 sync-app；不 push。
