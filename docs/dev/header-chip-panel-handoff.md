# 顶栏中间可点开详情 · 关键点

2026-10-27 · 用户体验设计师 → XBot 主管 / 执行官  
来源：政东「顶栏名字区完全没用；对标 Grok Bot 中间可点 → 右侧详情」  
候选：`正在干什么/06-XBot/候选/顶栏中间可点开详情.md`（实现中）  
对照：现网 `#info` / `.ptog` 同一右侧 Bot 信息面板；密度 step2 `.chd`；面板进出 **H10**；窄屏汉堡 **A5b**  
本批**不画**完整 hifi；关键点够编码。

---

## 产品一句

对话顶栏**身份区本身就是开关**：点头像+名字 → 右侧弹出该 Bot 的信息面板。不再靠右上角单独详情钮。

---

## 1. 芯片形态

| 项 | 定论 |
|---|---|
| 内容 | **头像（约 24）+ 展示名**；忙/副标若现网已有，可留在名字旁弱化，**算进同一可点块** |
| 长相 | 轻芯片：默认无描边重胶囊；**hover / 面板开**时浅底（对齐现网 fill）；圆角跟现网 icon 钮量级 |
| 位置 | 顶栏**水平中段**的身份块（对标 Grok：不是贴死左缘的只读标题）。宽屏：左可空、右可空，芯片居中偏视觉中。窄屏：见下 |
| 命中 | 整块可点（头像+名+其上浅底），最小高度跟顶栏行高；光标 pointer |
| 文案 | 可见字只有 Bot 名；`aria-label`：「打开信息」/ 开态「收起信息」（或带 Bot 名） |

不要：另起描边大胶囊、在名字旁加「详情」文字链、把全局设置塞进这块。

---

## 2. 开合反馈

- **同一面板**：就是现在的右侧 Bot 信息面板（详情 / 记忆 / 任务 / 轨迹 / 上下文），**不是**账号菜单里的设置浮层。
- **点芯片 = toggle**（开↔关），与旧 `#info` 行为一致。
- **开态**：芯片浅底 + `aria-expanded=true`；关态还原。
- **动效**：面板仍 **右进右出 `translateX`**（H10）；窄屏右侧抽屉从顶栏下沿到底（顶栏留在上面，芯片可再点收起），禁底栏 Y 向。
- **其它关闭**：面板内既有关法、Esc、（若有）遮罩 —— **保持**；不必为芯片新发明第三套。
- 键盘快捷键若现网已有（如 ⌘\）：可保留，**无可见重复钮**也行。

---

## 3. 右侧详情图标：**去掉**

**定论：删掉**对话顶栏右侧单独「详情 / 信息」icon（现网 `#info` / `.ptog` 可见钮）。

理由：芯片已是开入口；再留右侧钮 = **同权双入口**（经验 A）。政东痛点是中间没用、要对标 Grok 一块可点——主入口就应是芯片。

- 窄屏也**不要**为「可发现」再塞回右上详情钮。
- 面板厂头、折叠逻辑仍按 **H10**（厂头右仅编辑；··· 在侧栏 Bot 右键/长按）。
- **改写旧约定**：此前「面板折叠钮留在对话区右上」作废；开合主入口改为顶栏芯片。

---

## 4. 窄屏

| 区 | 内容 |
|---|---|
| 左 | 汉堡开 Bot 列表（**A5b** 不变：与头像同行垂直居中、左 pad 16、gap 8、高度含 safe-area） |
| 中 | **芯片**（头像+名）；开/关右侧面板 |
| 右 | **空**（不放详情 icon） |

芯片在汉堡与右缘之间居中排布即可；勿把芯片挤回汉堡旁变成「左堆标题」。

---

## 5. 群组 / 往来

- **1:1 Bot 对话**（主路径）：芯片 → 该 Bot 信息面板。
- **群组 / 多头像顶栏**（step2 peer 类）：整块身份芯片可点 → 打开**该会话已有**的信息面板；无独立面板的只读往来 → **不做假入口**（芯片可仍展示身份，不可点或点了无面板，勿跳全局设置）。
- 带「返回」的钻取顶栏：返回钮留左；芯片仍是中间身份，不跟返回抢。

本批不新做「群设置页」。

---

## 怎样算对

1. 点顶栏头像/名字 → 右侧 Bot 面板开；再点 → 关。  
2. 右上角单独详情 icon **不见了**。  
3. 开态芯片有浅底 / `aria-expanded`。  
4. 窄屏：左汉堡、中芯片、右无详情钮；面板仍右侧滑入。  
5. 打开的是 Bot 信息面板，不是全局设置。

## 不做

- 芯片进全局设置、设备、账号  
- 完整视觉剧本 / 新 token 大改（编码后可补一张开合对照）
