## 产品四句

1. 客户端与官网入口同一套主界面（侧栏 + 对话 + 右栏），不是另做薄壳。
2. 侧栏按设备分组 Bot；标题栏能看出当前 Bot 在哪台设备。
3. 一账号可绑多台设备；同一界面切换聊各机 Bot。
4. 官网入口不是设备；必须有绑定/配对产品面，列表里不出现「官网」。

## 怎样算对（含 G1）

1. **G1 同族**：并排放 step2 `01-main-trajectory` 与本稿主界面，侧栏/气泡/右栏一眼同族；禁止另起简化灰壳。
2. 公网登录后进同构主界面；侧栏 ≥2 设备组时，组头带设备名 + 在线/离线，其下该机 Bot。
3. 正在聊的 Bot：对话标题或副标题标所属设备（如「Mac Mini · 在线」）。
4. 官网入口侧栏没有「官网」或入口自身当设备组；底栏勿写「官网」当设备名。
5. 本机客户端：本机 Bot 在上（Bot·N），其它设备组在下；底栏主人 + 本机名。
6. 设置 → 设备：对齐 step2 15 密度（这台电脑卡、已绑多机、在线/离线、Bot 芯片、连接/网关一瞥）；**无官网行**；标题行右**唯一**主按钮「添加设备」；无底栏双 CTA。
7. 新电脑登录同账号后出现「把这台电脑绑到账号」确认；官网「添加设备」说明为主、短码为次。
8. 无设备空态：官网引导去电脑开 XBot 登录绑定。
9. 界面无工程词、无「添加服务器」、无架构模式开关。

## 本批的缩小与文案偏离（fix1，2026-10-26）

- 「绑定」只指把电脑认领到账号（`POST /api/account/claim`）；「配对」指用短码让两台电脑互用 Bot。侧栏、设置·设备列表和解除，用的都是配对，所以设置页写「配对后…」「已配对 · N」「解除配对」，不写「绑定」。
- 添加设备的说明写的是要配对一次，不再写「同账号登录并认领后这里就能看到」；原定的「也可以让对方输入下方短码（次要）」改成「让对方输入这个短码：」，因为现在短码就是唯一能用的跨机路径。
- 登录和注册不再静默绑定：本机登录后先看到「把这台电脑绑到账号？」，点了才绑。
- 输入对方短码的入口恢复了，但只是收起的次要文字按钮，不和「添加设备」同权。

## 还没做的

- 账号设备接到管道：只绑到同一账号、没有配对的电脑不进侧栏，也不能跨机聊（需要从账号设备换到管道连接的新机制，要先对照 ADR 0021、0024）。
- 本机 Bot 的对话标题副标没有标设备名（只有远端 Bot 有）。
- 账号解绑：账号服务没有解绑接口；「解除配对」只解除本机配对关系。
- 底栏「已绑定 N 台」按账号算，侧栏的组按配对表算，两边的数可能不一致。
