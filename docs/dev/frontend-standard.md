# 前端标准与布局迁移

## 授权与级别

L 档。用户于 2026-11-03 确认标准布局原型，并选择“按这版定稿，继续实施”。规范唯一入口为项目根 [design.md](../../design.md)。原型位于本机 `~/.xbot-build/ui-shots/frontend-standard/prototype/`。

本轮范围为视觉变量、公共控件、应用壳、记录页和设置模块。复用既有 DOM、接口和状态。原型假数据不进入产品。不改变聊天、环境流、子代理或设置保存语义。

## 怎样算对

关联规范中的 UC-UI-STD-01、02、03。已交付旅程要求继续有效。

- 普通控件 36px，单行列表 40px，双行列表最低 64px。设置菜单与配置操作同为 14px，辅助文字 12px。
- 侧栏、身份栏、标签、记录阅读宽度和设置壳符合确认原型。聊天输入与轨迹保留专用尺寸。
- 页面切换保留草稿、附件、引用、聊天节点和阅读位置。设置失败保留输入，关闭恢复入口焦点。
- 共用按钮、列表和弹层不再依赖技能页的样式归属。页面保留业务布局。
- 颜色和几何由统一 token 提供。普通列表无斑马纹。文字 Button 不配图标。
- 浅深主题、390px 手机与代表桌面场景没有遮挡、横向页面溢出或必要入口丢失。

## 结构与对照

选择语义 token 与共用 CSS。既有原生 JS 继续拥有数据、请求、挂卸载和草稿。备选公共 JS 工厂会扩大迁移面，且主要代填属性，因此不采用。

完整对照回顾与调用方示例见 [design.md](../../design.md)。独立设计审查已完成，五处规格歧义已修正。独立原型视觉评审 8/10，无必修问题。

ADR 0021、0042 和静态资源单源继续有效。保留设置关闭方式、图片生成细线与重启警示的局部约定。现行界面守护与 LESSONS 界面交互条目仍适用。结构决定见 [ADR 0074](../adr/0074-frontend-standard.md)。

## 实施与验证

先统一 token、公共控件和布局，再消除模块内冲突高度。迁移一族时删除该族旧定义，不保留另一套 CSS 覆盖层。设置与记录页只调整呈现，不改数据语义。

复用既有浏览器回归，验证聊天切页与草稿／滚动、记忆搜索与展开、设置主题／关闭／焦点、技能与供应商操作。使用既有真实 serve 冒烟检查资源装配和代表页面。模型只用 scripted/fake。

截图采用独立数据目录，输出至 `~/.xbot-build/ui-shots/frontend-standard/product/`。按主题、宽度和桌面壳实际影响取证。一次通过即停，不默认全仓或三遍。开发结果与日志在里程碑记录。
