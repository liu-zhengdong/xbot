# 顶栏中间可点开详情（dev）

候选：`候选/顶栏中间可点开详情.md`。

## 目标

对话顶栏中间做成 Grok Bot 式可点芯片；点击打开右侧信息面板；去掉只读标题+右侧详情双入口的浪费。

## 参考设计（关键点）

- 中间：`#title`（或包一层 button）= 头像+展示名，整块可点，toggle 现有 panel（同 `$("info")` 逻辑）。
- 去掉 `#info` 图标钮（默认）；窄屏若设计师要留第二入口再说。
- 面板仍是 Bot 信息抽屉（详情/记忆/任务/轨迹/上下文），**不是**全局设置浮层。
- 视觉：芯片感即可，勿重做整栏；对齐现 tokens。

## 底线

禁 sync-app；不 push；编码克制；允许反问；有 UI → 合入后喊设计师逛。
