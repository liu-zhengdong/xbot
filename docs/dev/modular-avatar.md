# 随机组合头像

Created: 2026-11-09

## 范围与授权

M 档。用户要求用 `/Users/liuzhengdong/xbot-design-assets/avatars` 替换现有头像，将人体、发型和表情等部件随机组合。
用户明确：“不用用户挑选，我的意思就是随机，随机到哪种是哪种。”
“标签”是“表情”的笔误。不提供部件编辑器或整图挑选网格。
长期需求与 UC 来源：[随机组合头像](</Users/liuzhengdong/Obsidian笔记/正在干什么/06-XBot/设计/组合头像.md>)。

审美顾问已交付内部部件原型，并验证下颌与衣服的遮挡修复。该原型只作素材对齐证据。
产品沿用现有头像区域，只保留当前头像、重新随机、上传，以及有上传图时的清除。

## 怎样算对

关联 UC-AVATAR-01：系统随机拼装小人，保存后保持同一组合，用户无需选择部件。

| 场景 | 预期结果 | 验证入口 |
| --- | --- | --- |
| 默认头像 | 使用新画风，由独立图层构成；同种子稳定 | 固定输出与浏览器 |
| 重新随机 | 只 PATCH avatar_seed，成功更新侧栏、顶栏和资料 | 浏览器行为 |
| 保存失败 | 原头像保留，错误可见，可重试 | 脚本化失败回包 |
| 新建 Bot | 初次生成随机种子；输入名字不换脸；保存显示的种子 | 浏览器＋真实接口 |
| 刷新与改名 | 保留原种子和组合 | 真实服务读回 |
| 上传与清除 | 上传仍有效；清除恢复之前组合 | 浏览器与原头像接口 |
| 远端与小图 | 同 seed 同部件；小图只改变裁切 | XBotFaces 与浏览器 |
| 图片装配 | 真实 PNG 可解码；支持认证与缓存；每份低于 700 KiB | 真实静态路由 |
| 界面 | 无挑选网格；既有操作可达；上下颌无明显错层 | 实际截图 |

按 docs/TESTING.md 选择相关检查一次，通过即停。原型不证明产品保存或端到端通过。

## 调用方与结构

```js
// 生成头像仍由一个种子决定。
const svg = XBotAvatar.portrait(bot.avatar_seed);
// 重新随机复用现有资料接口。
await api('/api/bots/' + encodeURIComponent(name), {
  method: 'PATCH', body: { avatar_seed: randomAvatarSeed() },
});
```

`entry.js` 唯一维护部件目录与固定随机算法。`build.js` 复制无依赖脚本到现有 vendor URL。
`portrait` 和 `face` 返回安全 SVG 文本。app 将 SVG 解析为真实 DOM，并缓存模板再克隆。
图像路径全部来自内置目录，不插入 seed 原文。SVG 不能作为带外部图的 img 数据 URL。
侧栏、资料和远端 XBotFaces 共用同一 renderer，16px 只调整 viewBox。

网页新建与重新随机使用 `xbot1:` 加随机 UUID。普通旧种子仍确定性映射到新部件。
现有 Config、资料 PATCH、模板、CLI 和网关都继续传 avatar_seed。上传和 glyph 保留原分支。

| 方案 | 访问路径 | 决定 |
| --- | --- | --- |
| A：现有 seed＋前端图层 | seed → 唯一部件目录 → SVG；随机操作 → 原资料 PATCH | 选用，持久化与远端链路保持单一 |
| B：avatar_parts＋服务端合成 | 新字段 → Go 合成 → 图片服务；扩展模板与远端 DTO | 不选，当前没有不可替代的收益 |

接受目录顺序与算法需冻结，换来不新增状态和协议。固定输出改变时须经用户授权。

## 素材规格

一个人体基底，加发型、上衣、表情、眼镜、头饰、胸饰和手持物七个随机槽。
叠层：bald → tops → chest → head → face → hair → glasses → headwear → props。
五十个 PNG 由用户源素材准备，空槽不加载图片。512px 图层合计 1,939,199 字节，最大 124,500 字节。
head 从原 1024px 基底提取，再与其他素材统一缩小，保留原对齐坐标。
身体与肤色的六张现有整图不打包，不将其当透明图层。

图片复用已认证的 `/api/ui/static/avatar-parts/…`，无需新增 Go 路由。本机与 pipe 使用同一资源源。
素材来源与处理脚本分别记录在 avatar-parts/SOURCE.txt 和 scripts/avatar/prepare.py。

## 验收结果

已达到端到端通过。随机头像浏览器用例覆盖稳定种子、真实图层解码、远端同种子、随机保存、失败重试、上传清除和新建。
首次用例命中保存后顶栏不刷新的缺陷，复用现有 refreshSavedProfile 后通过。原主人头像与流式资料刷新用例迁移为真实 HTTP 图层夹具，原行为断言保留。
资源、资料原子校验、新建种子、上传上限与清除、改名重开等定向回归通过。web vet、JavaScript 语法、固定输出与 diff 检查通过。

`TestRandomAvatarJourney` 用真实二进制和隔离数据验证随机保存、上传清除、刷新读回、改名保 seed 和进程重启保 seed。最新真实执行耗时 3.409 秒；不调用真实模型。
初次真实浏览器驱动假设支持 bot 查询参数，按实际入口改为点击侧栏。产品中重新随机后可能将头像顶边滚出可视区，已修正并新增真实滚动裁切检查。
DPR 2 产品证据位于 `/Users/liuzhengdong/.xbot-build/ui-shots/modular-avatar/product/`，覆盖桌面浅深色与 390px 手机。主 Agent 已查看最终截图。
本机 8788 的 app.js、头像脚本和基底图返回 dev-static，内容与源码一致。

Atlas、API 与长期设计已同步。文档 audit 退出 0，保留既有长度、旧 dev 和未映射告警。
