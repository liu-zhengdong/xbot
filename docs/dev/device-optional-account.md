# 本机可选账号

2026-10-27 · L 档。政东和设计师定稿：本机直接进主壳；账号在设置里可选登录、注册、退出；设备页区分账号状态；公网入口与订阅 OAuth 不变。实现复用本机账号 API，见 `~/.xbot-build/device-optional-account/handoff.md` 和本次用户补充。

## 怎样算对

无账号冷启动可用本机主壳与配对；设置账号可登录、注册、查看脱敏邮箱及退出；设备页展示本机匹配列表，已登录且未认领时可真实认领；头像菜单只有设置。公网入口仍需账号。冒烟用例：`internal/web/account_menu_browser_test.go`、`internal/web/local_session_test.go`（脚本替身；真实二进制旅程待验）。

## 对照回顾

复用 atlas 网页界面、现有账号及设备认领；ADR 0025 本机入口被 ADR 0030 替代，公网管道不变；守护旅程保留主人会话。账号绑定不等于设备配对，沿用多设备设计中的真实 API，不合并云设备列表。
