# 干完提议写成技能

主人完成可复用多步活后，Bot 在对话中说明刚做的事和下次如何唤起，给确认、改名、算了；主人确认或明确要求后走现有 `write_skill`。一次性、纯问答、已有等价技能不提，拒绝后不纠缠。空库也可提议。不新增确认卡、写锁或后台任务。

## 怎样算对

- 未确认前无新技能文件；确认后列表和加载认到。
- Dispatch 开着时主线 load skills 后仍可用 `write_skill`，权限保持 `review.Normal`。
- 相关测试通过。冒烟用例：`internal/kernel/skills_test.go` 的 `TestSkillHarvestProposalAndConfirmation`（脚本化内核对话）。
